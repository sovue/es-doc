The Python packages in vendor.zip are unmodified upstream source files.
engine.py is ES Doc's adapter for bounded reads, safe archive indexing,
path validation, split segments, streamed ZIP output and browser progress.
These tools do not execute game scripts or inject files into a game.
ZIP exports include original archive contents and an esdoc-report.txt file.
