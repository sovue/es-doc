Тестер варпера

В тестере кривая показана на перемещении, масштабе и прозрачности. Контурные маркеры показывают линейное изменение за то же время.

Выбранная криваяЛинейная: f(t) = t

{% for prop, title, range in [('xalign', 'Перемещение', 'xalign 0 → 1'), ('zoom', 'Масштаб', 'zoom 0.5 → 1'), ('alpha', 'Прозрачность', 'alpha 0 → 1')] %} {% endfor %}
t = 0.00 / f(t) = 0.000

Как написать формулу

t — прошедшая доля времени: 0 в начале, 1 в конце. Обычно f(0) = 0, f(1) = 1. Значения вне диапазона 0–1 дают отклонение за начальную или конечную точку. Для alpha результат ограничивается диапазоном 0–1.

Операторы: + - * / // % **, сравнения, and or not, a if условие else b. Функции: sin cos tan asin acos atan sqrt exp log floor ceil round abs min max pow. Константы: pi e.
