# Пользовательские спрайты

**Цель:** каталог `community-sprites.json` в es-doc-assets с форматом
`groups → variations → distances → [слои]`, предложенным пользователем.

**Решение:** сохранить плоский список ресурсов сообщества, добавив записи
вариантов с метаданными группы и дистанциями. Показывать их в группах на
существующей странице спрайтов. Отдельные изображения остаются совместимыми;
слои, используемые каталогом, не выводятся повторно отдельными спрайтами.
Автор и описание принадлежат группе. Используется существующий выбор дистанции.

**Пути:** пользователь подтвердил только локальные файлы es-doc-assets.
Относительный путь считается от community/. `/resource/raw/` адресует game/,
`/resource/community/` адресует community/. Выход за пределы этих папок запрещён.
Слои одной дистанции имеют одинаковые размеры и накладываются в порядке массива.

**План реализации:**

1. Добавить интеграционные тесты загрузки JSON, групп, поиска, порядка слоёв,
   дистанций, безопасности путей, обновления кэша и совместимости одиночных файлов.
   Запустить и подтвердить отсутствие новой функциональности.
2. Добавить загрузчик каталога и карту слоёв в CONFIG. Некорректные записи
   пропускать с предупреждением; при повреждённом JSON сохранять прежний каталог.
3. Расширить существующий конвейер сборки и миниатюр отдельным пространством
   кэша и маршрутами пользовательских спрайтов. Обновлять при изменении слоёв.
4. Добавить группировку на странице, автора и описание, переиспользуя выбор
   дистанции, просмотр, скачивание, фильтрацию и поиск.
5. Добавить документацию и пустой каталог в репозиторий ассетов. Запустить
   Python- и JavaScript-тесты, проверки синтаксиса и diff; проверить страницу.

**Технологии:** Python / FastAPI / Pillow, Jinja, существующий JavaScript.
